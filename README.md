A micro-startup pitch in one sentence: lazy AI agents that attend your startup's standups, nod, and say "no blockers" — for $99 a month, and they never wake up. Written for make.fun's "Absurd Micro-Startup Pitch-Off" bounty.

## Run it

```sh
node main.ts
```

Writes the pitch to `/output/entry.txt` (or `$OUTPUT_PATH` when set), with no trailing newline.
